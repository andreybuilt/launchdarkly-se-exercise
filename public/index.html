Context switcher

Pick a preset demo user, or "New visitor" for a freshly generated context that is not one of the demo- keys. Each preset is a multi-context: a user kind for the person and an organization kind for the account they belong to. This calls LaunchDarkly's identify() with the new context, so targeting (individual target and rule-based target) re-evaluates live.
